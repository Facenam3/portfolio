Getting Started

Prerequisites

Node.js

npm

Installation

Clone the repository:

git clone YOUR_PORTFOLIO_REPOSITORY_URL

Navigate to the project directory:

cd portfolio

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in your terminal.

Production Build

npm run build
